Features

Everything an agent needs.
Nothing it doesn't.

🤖

Autonomous Agent

  • Multi-step task execution from a single prompt
  • Shadow-git checkpoints with hunk-level undo
  • Detached background runs → GitHub PRs
🧠

Editor Intelligence

  • Ghost-text autocomplete — Tab to accept
  • Inline edit (Ctrl+I) with diff review
  • Fix, Explain, Generate Tests code actions
🌐

Agent Browser

  • Live screencast of the agent browsing
  • Take over mid-task, hand control back
  • Policy-gated: file:// and private IPs blocked
🗣️

Voice Experimental

  • Speak prompts via Web Speech API
  • Spoken responses, mic input
  • No audio ever touches Sunday servers
💻

Multiple Frontends

  • VS Code extension, Sunday IDE, CLI
  • JetBrains plugin (in progress)
  • Hosted OpenAI-compatible gateway
🔧

Developer Tools

  • MCP servers: stdio + Streamable HTTP
  • Skills with trust gating
  • Terminal integration with error explain

How it works

The agent loop, step by step.

Scroll — the loop fills at your pace.

1

Plan

Plans the change, breaking it into steps.

2

Read

Reads your codebase with semantic context retrieval.

3

Edit

Edits files — you review the diff before anything lands.

4

Run

Runs terminal commands, with your approval.

5

Verify

Verifies the result with a built-in verifier agent.

6

Checkpoint

Checkpoints everything — shadow-git undoes any hunk.
