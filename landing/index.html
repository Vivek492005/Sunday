A world-class code editor at its core

Sunday is built on VS Code 1.140 — the editor millions of developers trust. Ghost-text autocomplete, inline edits with diff review, code actions, and terminal intelligence come standard. Switch between agents and hands-on coding in the same window.

  • Ghost-text autocomplete (Tab to accept)
  • Inline edit with diff review
  • @-mentions: file, symbol, terminal, git-diff, web
  • Commit message generation
