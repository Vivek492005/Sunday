Sunday — The Agent-First Coding IDE

Your AI pair programmer, built into your editor. Sunday is a VS Code-based IDE with a built-in autonomous coding agent — not a chatbot bolted on, but an agent-first development environment.

✨ Features

  • 🤖 Parallel agents — bounded pool, conflict detection, single verifier
  • 🧠 Hierarchical orchestration — context-centric task decomposition
  • 🌐 Browser agent — live screencast, takeover mode
  • 🔌 MCP support — stdio + Streamable HTTP, namespaced tools
  • 🔒 Security — taint tracking, secret redaction, STRIDE threat model

🚀 Quick start

# Download the installer from Releases, or:
pnpm install
pnpm -r build
pnpm -r test   # 800+ tests green
