Release Notes

What shipped, what changed, and what's coming next. Beta users receive every release automatically through the beta auto-update channel.

Latest release

Latest v1.0.0-beta.1

Released October 9, 2026 · Windows / macOS / Linux · GitHub release

The first public beta of the Sunday IDE. Full VS Code-compatible editor with the Sunday agent stack, zero-config free tier, and beta auto-updates.

Highlights

Coding Streaks

Gamification

Daily coding streaks with a status-bar fire indicator. Streak Freeze banks protection against missed days, and Vacation Mode pauses counting during planned breaks. Streaks pay out in quota: 7 days → +100 requests/day, 30 days → +500/day.

Admin Gateway

Platform

A separate administrator login with full bypass of rate limits and quotas for operations and support. Admin sessions are issued and refreshed through dedicated endpoints with strict allowlisting.

Anti-Abuse Protection

Security

Free-tier fairness guardrails: max 2 distinct accounts per machine per 24 hours. Paid plans bypass the restriction. Keeps the 200 req/day free tier sustainable for genuine users.

Beta Auto-Updates

Platform

Beta installs now resolve the latest prerelease from the releases feed instead of only stable builds. Help → Check for Updates delivers beta builds in one click, and future updates download automatically. Stable installs are never offered beta builds.

GitHub Integration

Onboarding

Sign in with GitHub alongside Google and Microsoft, plus one-click repository import — paste a repo URL and start working with agents immediately.

Windows CI Fixes

Engineering

Five Windows-specific CI failures fixed; the full test matrix is green on Linux, macOS, and Windows. A new fast CI pipeline catches regressions in about 5 minutes.

Coming soon Roadmap

What we're building next. Dates are intentionally not promised — beta feedback sets the order.

  • Quests and achievements

    The next engagement layer after streaks: guided quests for learning agent workflows, and achievements for milestones like your first swarm or 10 merged PRs.

  • Ranks, squads, and leagues

    Social coding: seasonal leagues, team squads, and visible ranks for consistent builders. Designed, not yet shipped.

  • Durable billing backend

    Paddle checkout is decided; the production billing service (subscriptions, webhooks, durable session storage) lands with the first paid-tier launch.

  • JetBrains plugin

    The sunday-agent experience for IntelliJ-based IDEs — chat tool window, editor actions, and daemon protocol client are built; packaging and release are next.

  • npm: @sunday/cli

    The Sunday CLI for terminal-first agent workflows, published to npm.

  • Stable 1.0

    The beta channel graduates: hardened auto-update rehearsals, accessibility pass, and the full engagement suite.
