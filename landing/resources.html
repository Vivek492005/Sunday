Contributing

Sunday is Apache-2.0 and community-driven. Here's how to get involved:

  1. Find an issue — browse open issues; newcomer-friendly ones are labeled for first-time contributors.
  2. Fork and branch — fork the repo, create a feature branch, and make your change with tests.
  3. Open a pull request — describe what changed and why. CI runs the full matrix (Windows, macOS, Linux) on every PR.
  4. Docs count too — fixing a tutorial, clarifying the FAQ, or adding a glossary term are all valuable contributions.

Ground rules: be kind, keep PRs focused, and don't commit secrets. The full contribution guide lives in CONTRIBUTING.md at the repo root.
