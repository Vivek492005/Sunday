## Appendix A.6 manual QA checklist — status

The A.6 checklist (fresh install → onboarding → provider → ask/plan/approve →
edits → approvals → 429 force → Relay marker → kill sidecar → resume →
untrusted workspace → MCP → skills → inline edit → autocomplete → parallel
agents → merge → browser verify → uninstall/reinstall) has **not** been
executed end-to-end as a release ritual. Pieces are covered by automated
tests (sidecar lifecycle, relay, MCP, orchestration, browser policy), but
the human walkthrough — especially *uninstall/reinstall keeps settings*
and *kill `sundayd` → session resumes* on Windows — is unrecorded.
